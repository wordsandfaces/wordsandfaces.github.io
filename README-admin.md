# Админ-панель «Слова И Лица»

Скрытая панель для правки `faces.js` прямо в браузере. Сохраняет изменения
коммитом в GitHub — сайт на GitHub Pages пересобирается автоматически.

## Как открыть

```

https://wordsandfaces.ru/admin.html

```

Ссылки на неё нигде на сайте нет, страница закрыта от индексации
(`noindex, nofollow`). Достаточно добавить её в закладки.

## Первый запуск: токен GitHub

Панель не хранит паролей. Вместо пароля — **fine-grained personal access
token**, который выдаёт сам GitHub и который можно отозвать в любой момент.

1. Откройте https://github.com/settings/personal-access-tokens/new
2. **Token name**: `waf-admin` (любое)
3. **Expiration**: 90 дней (или больше, как удобно)
4. **Repository access** → `Only select repositories` → выберите
   **`wordsandfaces.github.io`**
5. **Permissions** → `Repository permissions` → найдите **Contents** →
   поставьте **Read and write**. Больше ничего не нужно.
6. Нажмите `Generate token` и скопируйте строку `github_pat_...`
   (показывается один раз).
7. Вставьте токен в панели входа и нажмите «Войти».

Токен хранится в `localStorage` этого браузера. На чужом компьютере
снимайте галочку «Запомнить» или жмите «Выйти и забыть токен».

## Что умеет

**Вкладка «Карточки»**
- список всех актёров с поиском по имени, городу, образованию;
- форма со всеми полями `faces.js` (имя, пол, возраст, город, рост,
  телосложение, волосы, глаза, образование, фото, галерея, видео,
  filmtoolz, telegram, флаг `noModal`);
- галерея редактируется как список URL — по одному в строке;
- кнопки: поднять / опустить / дублировать / удалить;
- кнопка «+» добавляет новую карточку в начало списка;
- ссылка «Открыть на сайте» ведёт на `index.html?actor=<slug>` — тот же
  slug, что строит `script.js`, поэтому ссылка откроет нужную модалку;
- живое превью фото и подписи.

**Вкладка «faces.js»**
- полный текст файла в том же формате, в котором он лежит в репозитории;
- «Форматировать» — проверка синтаксиса;
- «Применить к данным» — разобрать текст обратно в карточки.

**Вкладка «Настройки»**
- owner / repo / branch / путь к файлу (по умолчанию уже верные);
- скачать `faces.js` локально;
- загрузить `faces.js` из файла (замена всех данных);
- статус аккаунта и проверка права на запись в репозиторий.

**Сохранение**
- кнопка «Сохранить в GitHub» или `Ctrl+S`;
- панель сама читает текущий `sha` файла и делает `PUT /contents/...`;
- внизу появится ссылка на коммит;
- GitHub Pages обновляет сайт примерно за минуту.

## Если что-то пошло не так

| Симптом | Причина | Что делать |
|---|---|---|
| `GitHub отклонил токен (401)` | токен истёк или отозван | выпустить новый |
| `Репозиторий не найден или нет доступа` | в токене не выбран этот репозиторий | отредактировать токен → Repository access |
| `Доступ на запись: только чтение` | Contents стоит `Read` | поменять на `Read and write` |
| `Конфликт: файл на GitHub изменился` | файл правили в другом месте | обновить страницу, заново войти |
| Сохранилось, а сайт старый | GitHub Pages ещё собирается | подождать 1–2 минуты, обновить с `Ctrl+F5` |

## Безопасность — честно

Это статический сайт, серверной части нет. Поэтому:

- **Реальный замок — токен.** Без действующего токена с правом записи в
  репозиторий панель ничего не сохранит. Токен есть только у вас.
- **Адрес `admin.html` — не секрет, а просто неафишируемая страница.**
  Если кто-то её откроет, он увидит экран входа и ничего больше.
- **Токен лежит в `localStorage`.** Не входите на чужих компьютерах и не
  ставьте галочку «Запомнить», если устройство не ваше.
- Токен уходит только на `api.github.com`. Никакой аналитики и сторонних
  запросов на странице нет.

## Отзыв доступа

В любой момент: https://github.com/settings/tokens → найти токен →
`Delete`. После этого панель перестанет сохранять, а данные на сайте
останутся нетронутыми.
